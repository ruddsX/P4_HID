# P4_HID 🎮

**P4Hid** is a high-performance hardware bridge designed to seamlessly unify dual-PC (2PC) and single-PC (1PC) hardware-assisted input configurations. By functioning as a transparent intermediary, P4Hid allows you to externally inject precise, real-time mouse or controller movement data into your primary system simultaneously with your physical inputs.

---

## 🚀 Key Features

* **True Hardware Emulation:** To the host operating system, the device registers identically to a standard, physically connected mouse or controller.
* **Simultaneous Input Injection:** Enables smooth, concurrent merging of physical user inputs and synthetic programmatic movements.
* **Eliminates Input Lock:** Completely bypasses software-level "mouse lock" restrictions where operating systems limit control to a single primary pointer.
* **Zero Host-Software Overhead:** Operates entirely at the hardware level, completely eliminating the need for custom kernel-mode or user-mode software applications on your target machine.
